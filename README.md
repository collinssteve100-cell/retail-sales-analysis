# Retail Sales & Customer Performance Analysis

An end-to-end Data Analyst portfolio project focused on sales, profitability, customers, regions, product categories, discounts, and operational performance.

**Dataset:** Synthetic retail transaction data created specifically for this portfolio. It contains no confidential information.

## Business Questions
- What are total sales, profit, orders, customers, margin, and average order value?
- How do sales and profit change over time?
- Which regions and categories perform best?
- Which customers generate the most value?
- How do discounts affect profitability?
- Which product areas need attention?

## Tools
SQL, Python, Pandas, Matplotlib, Excel/BI-ready data, Git/GitHub

## Workflow
1. Raw data profiling
2. Data cleaning and validation with Python
3. SQL business analysis
4. KPI and trend analysis
5. Visualization
6. Business recommendations
7. Dashboard-ready output
